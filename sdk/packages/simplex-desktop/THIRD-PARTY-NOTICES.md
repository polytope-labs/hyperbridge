# Third-party notices

Simplex Desktop includes Electron and Chromium. Their license texts ship beside the installed
application resources:

- `LICENSE.electron.txt` — Electron's MIT license;
- `LICENSES.chromium.html` — Chromium and the third-party software distributed with Chromium.

The packaged Simplex runtime also retains the license files supplied by its production npm
dependencies under `node_modules`.
