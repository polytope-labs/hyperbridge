# Free RPC endpoints

Every `[[chains]]` entry lists its RPC endpoints in `rpcUrls`. You don't need a paid provider to start. The endpoints on this page are free, need no account or API key, and passed testing against Simplex's gateway scan.

The setup wizards and the dashboard's Chains panel start each mainnet chain with the defaults listed for it below. You can edit the list before the config is written, and at any time afterwards.

Free endpoints are shared by everyone who uses them, so they rate-limit and fall behind at times. A paid provider gives you more headroom. You can mix the two: put your paid endpoint first and keep free ones in the list for the [quorum](/developers/evm/simplex/confirmations#rpc-quorum).

## What an endpoint has to do

Simplex scans each chain for gateway events every `blockScanIntervalSeconds`, which defaults to 3 seconds. Each scan sends `eth_blockNumber` and `eth_getLogs` to every endpoint in the chain's list. So an endpoint has to answer both calls every few seconds without throttling.

- It must serve `eth_getLogs` across the blocks one scan covers. On Arbitrum that is about 12 blocks.
- Each URL in `rpcUrls` needs its own hostname. Simplex rejects a list that repeats one, so several paths on one host count once.
- Use one endpoint per operator. Two URLs from the same provider agree with each other by construction, so the second adds nothing to the quorum. The defaults follow this rule.

## How they were tested

Each endpoint first ran alone, as the only RPC for its chain, under `simplex run --watch-only`. Every HTTP endpoint that chainlist.org lists for the chain ran for 2 minutes. Those that finished without errors and kept up with the chain then ran for 20 minutes. These runs took place on 16–18 September 2026, with simplex 0.16.2.

The defaults then ran together in a quorum for 19 hours. Endpoints that were set aside often during that run were left out of the defaults, and are listed below as alternatives. A later 16-hour run, on 24–25 September, is where the notes on individual defaults come from.

Keep in mind:

- All tests ran from one IP address. Fillers that share an IP also share each provider's limits.
- A 20-minute run can't catch hourly or daily quotas.
- No orders were placed during the solo runs, so they show that an endpoint can scan, not that it delivered an order.
- Free endpoints come and go. Watch your own logs before relying on any list.

## When an endpoint struggles

With more than one URL, Simplex reads through a quorum: a scan's result counts only once enough endpoints agree on it. An endpoint that rate-limits is set aside for as long as its `Retry-After` header asks, up to 5 minutes. An endpoint that falls behind the others is set aside for 15 seconds. The quorum is then worked out over the endpoints still answering. So one struggling free endpoint costs you nothing, as long as enough of the others keep up.

Reads outside the quorum go to your first healthy endpoint. These include balance reads, gas estimation and transaction submission. Put the endpoint you trust most first.

## BNB Smart Chain (56)

```toml lineNumbers
[[chains]]  # BNB Smart Chain
rpcUrls = [
    "https://bsc-rpc.publicnode.com",
    "https://public-bsc-mainnet.fastnode.io",
    "https://public-bsc.nownodes.io",
    "https://bsc.blockrazor.xyz",
    "https://rpc-bsc.48.club",
    "https://bsc.api.pocket.network",
]
```

None of these was set aside during the 16-hour run. Alone, `public-bsc.nownodes.io` missed the odd scan.

Also passed, not in the defaults:

- `https://56.rpc.thirdweb.com` and `https://rpc-bsc.blockmachine.io` were rate-limited often in the quorum run.
- `https://bsc.rpc.sentio.xyz` fell behind the others for most of the quorum run.
- `https://0.48.club` is the same operator as `rpc-bsc.48.club`, so use one of the two.

Avoid:

- Every `bsc-dataseed*` host, `binance.nodereal.io` and `bsc.meowrpc.com` refuse `eth_getLogs`. Simplex logs this as rate limiting, but it never clears. A chain with only these endpoints starts and never sees an order.
- `bsc.drpc.org`, `public.1rpc.io/bnb` and `bnb.api.onfinality.io/public` rate-limit from the first request.

## Ethereum (1)

```toml lineNumbers
[[chains]]  # Ethereum
rpcUrls = [
    "https://mainnet.gateway.tenderly.co",
    "https://rpc.mevblocker.io",
    "https://ethereum-rpc.publicnode.com",
    "https://ethereum.public.blockpi.network/v1/rpc/public",
    "https://eth.blockrazor.xyz",
    "https://eth.api.pocket.network",
    "https://ethereum-public.nodies.app",
    "https://eth-mainnet.public.blastapi.io",
    "https://public-eth.nownodes.io",
]
```

In the 16-hour run, `public-eth.nownodes.io` was rate-limited 126 times and sat out about two-thirds of the run. The other eight carried the quorum without it. `ethereum-public.nodies.app` and `eth-mainnet.public.blastapi.io` were rate-limited a few times each.

Also passed, not in the defaults:

- `https://gateway.tenderly.co/public/mainnet` is the same operator as `mainnet.gateway.tenderly.co`, so use one of the two.
- `https://mainnet.rpc.sentio.xyz` missed the odd scan alone and fell behind the others for most of the quorum run.
- `https://rpc-eth.blockmachine.io` fell up to 36 seconds behind at times alone, and was rate-limited often in the quorum run.

Avoid:

- `rpc.flashbots.net` refuses `eth_call`.
- `cloudflare-eth.com` fails every scan with "Cannot fulfill request".
- bloXroute's Ethereum endpoints (`*.rpc.blxrbdn.com`) and `eth.meowrpc.com` refuse `eth_getLogs`.
- `eth.drpc.org` and `public.1rpc.io/eth` rate-limit during scans.

## Arbitrum One (42161)

```toml lineNumbers
[[chains]]  # Arbitrum One
rpcUrls = [
    "https://arbitrum-one-rpc.publicnode.com",
    "https://arbitrum.gateway.tenderly.co",
    "https://arbitrum.drpc.org",
    "https://public-arb-mainnet.fastnode.io",
    "https://arb-one.api.pocket.network",
    "https://arbitrum-one-public.nodies.app",
    "https://arb1.arbitrum.io/rpc",
]
```

In the 16-hour run, `arb-one.api.pocket.network` and `arbitrum-one-public.nodies.app` each fell behind the others a few hundred times, 15 seconds at a time. `arb1.arbitrum.io` was rate-limited 20 times. The quorum still had at least four endpoints answering throughout.

Also passed, not in the defaults:

- `https://rpc-arbitrum.blockmachine.io` and `https://42161.rpc.thirdweb.com` were rate-limited often in the quorum run.
- `https://arbitrum-one.rpc.sentio.xyz` fell behind the others for most of the quorum run.
- `https://rpc.swiftnodes.io/rpc/arbitrum` missed scans alone and was rate-limited often in the quorum run.

Avoid:

- `arbitrum-one.public.blastapi.io` caps `eth_getLogs` at 10 blocks, fewer than one scan covers. It works on other chains.
- `arbitrum.meowrpc.com` refuses `eth_getLogs`.

## Base (8453)

```toml lineNumbers
[[chains]]  # Base
rpcUrls = [
    "https://base-rpc.publicnode.com",
    "https://base.gateway.tenderly.co",
    "https://base.public.blockpi.network/v1/rpc/public",
    "https://base.rpc.blxrbdn.com",
    "https://rpc.baseazul.dev",
    "https://mainnet.base.org",
    "https://base-public.nodies.app",
]
```

`mainnet.base.org` rate-limits the burst of `eth_call`s Simplex sends at startup to read token decimals. Simplex then uses the decimals from its token registry, and scanning is unaffected. In the 16-hour run, `base-public.nodies.app` was rate-limited a few times.

Also passed, not in the defaults:

- `https://8453.rpc.thirdweb.com` was rate-limited often in the quorum run.
- `https://base.rpc.sentio.xyz` fell behind the others for most of the quorum run.
- `https://rpc.swiftnodes.io/rpc/base` fell up to 16 seconds behind at times alone.
- `https://gateway.tenderly.co/public/base` and `https://developer-access-mainnet.base.org` are the same operators as defaults, so use one of each pair.

Avoid:

- `base.drpc.org`, because `eth_getLogs` times out on the free plan. drpc works on Arbitrum and Polygon.
- `base.api.pocket.network`, because some scans fail with "historical state is not available". Pocket works on the other chains.
- `base-mainnet.public.blastapi.io`, which rate-limits during scans.

## Endpoints to avoid on every chain

- Tatum's gateways (`*.gateway.tatum.io`) allow 5 requests a minute, so no scan completes.
- ZAN (`api.zan.top`) refuses `eth_getLogs` without a registered account.
- Lava's endpoints (`*.lava.build`) are retired and answer 410.
- Satelink (`rpc.satelink.network`) answers 402 and asks for payment.
- Alchemy's `/v2/demo` URLs rate-limit from the first request.
- URLs with an API key in them, as endpoint directories publish them. Everyone using one shares its quota, and the keys stop working without notice.

Some endpoints answer `curl` but refuse requests from Node, which Simplex uses. Test a new endpoint with Simplex itself: run `simplex run --watch-only` with it as the chain's only `rpcUrls` entry, and watch the log for scan errors.
