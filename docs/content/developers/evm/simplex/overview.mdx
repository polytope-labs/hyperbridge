# Simplex

Simplex is an automated binary that monitors Intent Gateway orders and fills them profitably. You set its prices by posting limit orders, which Simplex advertises on the HyperFX orderbook. It watches the chains you configure for `OrderPlaced` events and waits for enough confirmations for the order's value. It then prices each order against your limit orders and bids when one covers it. Solvers earn the difference between an order's inputs and outputs.

## Requirements

You need an EVM wallet (configured via `[simplex.signer]`) funded with native tokens for gas and stablecoins to fill orders with — minimum $10,000 equivalent per chain is a reasonable starting point. To sell a non-USD token, such as cNGN, hold it on each chain you fill on. You also need a Substrate account with BRIDGE tokens for Hyperbridge extrinsic fees. A successful bid also locks a deposit, reclaimed by retracting the bid. Simplex retracts automatically when it sees the order filled, and a periodic sweep retries anything that failed — but **stopping the solver does not sweep**, so a bid still unretracted at shutdown stays locked until the next run picks it up. That is why the bid store must be durable.

RPC endpoints must be from a premium provider (Alchemy Pro, Infura Growth+, QuickNode Pro). Archive node access is required for storage slot queries and gas simulation. Free-tier RPCs will not work reliably. For chains that can source cross-chain orders, configure at least two organisationally independent providers in `rpcUrls` — see [RPC Quorum](/developers/evm/simplex/confirmations#rpc-quorum).
